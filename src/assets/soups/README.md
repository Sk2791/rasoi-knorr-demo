# Soup photos — sources & licenses

Shared pool of hot soup photography, used as a card's background whenever it
isn't showing that region's own landmark photo. This app only ever advertises
Knorr instant soup — every image here is soup, never any other snack, dish,
or food category, so the stock photography stays on-brand throughout (this
replaced an earlier mixed "snacks" pool and a separate "region food" pool of
real regional dishes like biryani or dhokla, both retired for the same
reason). Sourced from Wikimedia Commons; all freely licensed.
